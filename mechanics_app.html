(1) 斜面を滑る時間 $t_1$ と垂直抗力 $N$

求めたいのは $t_1$ と $N$ の2つです。「滑らか」なので摩擦なし。斜面方向の力は重力の成分だけなので、力→加速度→等加速度の式で時間、と順番に求められます。$N$ は斜面に垂直な方向のつり合いです。
1.「滑らかな斜面」なので摩擦はありません。斜面に沿った力は重力の斜面成分 $mg\sin 30°$ だけです。
2.❷運動方程式 $ma = F$ を斜面方向に立てます。$ma = mg\sin 30°$
3.両辺を $m$ で割ると、$a = g\sin 30° = g/2$ です。
4.斜面に垂直な方向は動かない（加速度0）ので、力のつり合いから $N = mg\cos 30° = \frac{\sqrt{3}}{2}mg$ です。
5.斜面の距離は $s = h / \sin 30° = 2h$ です。
6.初速0なので、❶等加速度 $s = \frac{1}{2}at^2$ に代入します。$2h = \frac{1}{2} \cdot \frac{g}{2} \cdot t_1^2$ ……①
7.①を整理すると $t_1^2 = 8h/g$ なので、$t_1 = 2\sqrt{2h/g}$ です。
$t_1 = 2\sqrt{2h/g}$　　$N = \frac{\sqrt{3}}{2}mg$

(2) B点での速さ $v$

初速0で高さ $h$ を降りてきただけです。「高さの差」と「速さ」を直接つなげるエネルギーの方法が一番かんたんです。
1.経路に関係なく速さが出せる❸エネルギー保存則 $\frac{1}{2}mv^2 + mgh = \text{一定}$ を使います。
2.A（高さ $h$、速さ0）とB（高さ0、速さ $v$）で保存則を立てます。$mgh = \frac{1}{2}mv^2$
3.両辺を $m$ で割って $v^2 = 2gh$、よって $v = \sqrt{2gh}$ です。
$v = \sqrt{2gh}$

(3) 水面到達時間 $t_2$

B点から先は空中の放物運動です。水面までの距離は不明ですが、「60°で飛び込む」という速度の向きの条件があります。速度成分を求めて角度条件に代入すれば $t_2$ が出ます。
1.B点から先は放物運動です。水平と鉛直に分けます（❼斜方投射の考え方）。
2.B点の速度を分解します。水平 $v_x = v\cos 30° = \frac{\sqrt{3}}{2}v$（一定）、鉛直の初速 $v_{y0} = v\sin 30° = \frac{v}{2}$（下向き）
3.鉛直の速さは重力で増えるので、❶等加速度より $v_y = v_{y0} + gt_2 = \frac{v}{2} + gt_2$
4.「60°で飛び込む」＝水面で速度の向きが水平から60°。条件は $v_y / v_x = \tan 60° = \sqrt{3}$
5.角度の条件に速度成分を代入します。$\frac{\frac{v}{2} + gt_2}{\frac{\sqrt{3}}{2}v} = \sqrt{3}$　→　$\frac{v}{2} + gt_2 = \frac{3}{2}v$ ……①
6.①を整理すると $gt_2 = v$、$t_2 = v/g = \sqrt{2h/g}$ です。
$t_2 = v/g = \sqrt{2h/g}$

(4) 水面からB点の高さ $H$

$t_2$ の間に鉛直方向に落ちた距離＝高さ $H$ です。加速度・初速・時間がすべてわかっているので、等加速度の距離の式に当てはめます。
1.❶等加速度 $s = v_0 t + \frac{1}{2}gt^2$ に代入します。$H = \frac{v}{2} \cdot t_2 + \frac{1}{2}g \cdot t_2^2$
2.$t_2 = v/g$ を代入します。$H = \frac{v}{2}\cdot\frac{v}{g} + \frac{1}{2}g\cdot\frac{v^2}{g^2} = \frac{v^2}{2g} + \frac{v^2}{2g} = \frac{v^2}{g}$
3.さらに $v^2 = 2gh$ を代入して $H = 2gh/g = 2h$ です。
$H = v^2/g = 2h$

(1) P,Qが静止する $M$ の範囲

「静止」＝加速度0＝力のつり合い。摩擦があるので、Pが落ちそうな場合と引き上げられそうな場合の2方向を考え、不等式を2本立てます。
1.加速度0なので力のつり合いです。Pに働く力を整理します。糸の張力 $T = Mg$ ……①、重力の斜面成分 $mg\sin 30° = mg/2$ ……②
2.最大静止摩擦力は $f_{\max} = \mu_s \cdot mg\cos 30° = \frac{\sqrt{3}}{2}\mu_s mg$ ……③ です。
3.Pが落ちそうな場合（摩擦は上向き）：$T + f_{\max} \geq mg\sin 30°$ に①②③を代入します。$Mg + \frac{\sqrt{3}}{2}\mu_s mg \geq \frac{mg}{2}$
4.$M$ について整理すると $M \geq \frac{m}{2}(1 - \sqrt{3}\,\mu_s)$ ……④
5.引き上げられそうな場合（摩擦は下向き）：$mg\sin 30° + f_{\max} \geq T$ に①②③を代入します。$\frac{mg}{2} + \frac{\sqrt{3}}{2}\mu_s mg \geq Mg$
6.$M$ について整理すると $M \leq \frac{m}{2}(1 + \sqrt{3}\,\mu_s)$ ……⑤
7.④⑤を合わせて、問題の $\mu_s$ の値を代入すれば $M$ の範囲が出ます。
$(3-\sqrt{3})\,m/6 \leq M \leq (3+\sqrt{3})\,m/6$

(2-ア) $M = \frac{3}{2}m$ のとき、加速度 $a$ と速さ $v$

$M$ が大きいので系全体が動きます。糸でつながっていて加速度は同じなので、系全体でまとめて運動方程式を立てます。
1.P・Qは糸でつながっていて加速度は同じ $a$ です。系全体で❷運動方程式を立てます。
2.駆動力（Q側）$= Mg = \frac{3}{2}mg$、抵抗（P側）$= mg\sin 30° + \mu_k mg\cos 30°$
3.❷運動方程式 $(M+m)\,a = $ 駆動力 $-$ 抵抗 に代入して整理すると、$a = 3g/10$ です。
4.初速0なので、❶等加速度 $v^2 = 2ah$ に代入します。$v^2 = 2 \cdot \frac{3g}{10} \cdot h = \frac{3gh}{5}$
5.よって $v = \sqrt{3gh/5}$ です。
$a = 3g/10$　　$v = \sqrt{3gh/5}$

(2-イ) Q着地後、Pが止まるまでの距離 $l$ と時間 $t$

Q着地で糸がゆるみ、Pは速さ $v$ で斜面を上昇中。重力成分と摩擦がどちらも減速方向に働きます。減速度→停止距離→時間と順番に求めます。
1.Qが着地すると糸がゆるみ、Pだけが速さ $v$ で斜面を上ります。
2.Pに働く減速力は $mg\sin 30° + \mu_k mg\cos 30°$ です。どちらも上りを止める向きに働きます。
3.❷運動方程式より $a_2 = g\sin 30° + \mu_k g\cos 30°$ です。
4.初速 $v$ で減速して止まるまでの距離を求めます。❶等加速度 $v^2 = 2a_2 d$ より $d = v^2/(2a_2)$ です。
5.つながっている間にPは斜面を $h$ 上がっているので、Pが最初にいた位置からの合計距離は $l = h + d$ です。
6.時間は2区間に分けます。連結中 $t_1 = v/a$（(2-ア)の $a$）、単独 $t_2 = v/a_2$ です。
7.値を代入して整理すると $l = 7h/5$、$t = t_1 + t_2 = 14v/(3g)$ です。
$l = 7h/5$　　$t = 14v/(3g)$

(1) B点・C点での速さ $v_B$, $v_C$

円弧上の運動なので等加速度は使えません。摩擦なしなので高さの差だけで速さが決まるエネルギーの方法を使います。
1.「滑らか」なので❸エネルギー保存則 $\frac{1}{2}mv^2 + mgh = \text{一定}$ が使えます。高さの基準をBにとります。
2.AはBより $r$ 高い位置です。A→Bで $mgh$ がすべて運動Eに変わるので $mgr = \frac{1}{2}mv_B^2$ → $v_B = \sqrt{2gr}$
3.CはBより $r(1-\cos 60°) = r/2$ 高い位置です。$mg \cdot r/2 = \frac{1}{2}mv_C^2$ → $v_C = \sqrt{gr}$
$v_B = \sqrt{2gr}$　　$v_C = \sqrt{gr}$

(2) AC間で重力と垂直抗力がする仕事

重力の仕事は高さの差だけで決まります。垂直抗力は動く方向と常に直角なので仕事ゼロです。
1.重力の仕事は経路によらず高さの差で決まります。AからCへ $r/2$ 下がったので $W_g = mg \cdot r/2 = mgr/2$ です。
2.垂直抗力は面に垂直で、速度の向きと直角です。力と移動方向が直角 → $W_N = 0$ です。
$W_g = mgr/2$　　$W_N = 0$

(3) 最高点Dの速さ $v_D$ と床からの高さ $h$

Cで離れた後は放物運動です。最高点では鉛直速度が0なので、速さは水平成分だけ。高さはCからの上昇分を足します。
1.C点での速度は円弧の接線方向（水平から60°上向き）です。水平と鉛直に分けます。$v_{Cx} = v_C\cos 60° = \frac{\sqrt{gr}}{2}$、$v_{Cy} = v_C\sin 60° = \frac{\sqrt{3gr}}{2}$ ……①
2.最高点Dでは鉛直速度が0です。水平成分は変わらないので $v_D = v_{Cx} = \frac{\sqrt{gr}}{2}$ です。
3.鉛直方向の上昇高さを求めます。❶等加速度 $0 = v_{Cy}^2 - 2g\Delta h$ より $\Delta h = v_{Cy}^2/(2g)$
4.ここに①を代入すると $\Delta h = 3gr/(4 \cdot 2g) = 3r/8$ です。
5.C点の高さは $r/2$ なので、Dの高さは $h = r/2 + 3r/8 = 7r/8$ です。
$v_D = \sqrt{gr}/2$　　$h = 7r/8$

(4) 床衝突速さ $v_E$

途中の経路は複雑ですが、摩擦なしなのでエネルギーはずっと保存。結局「高さ $r$ を降りた」だけで速さが出ます。
1.A→E全体で摩擦なし → ❸エネルギー保存則を1本。$mgr = \frac{1}{2}mv_E^2$
2.解くと $v_E = \sqrt{2gr}$ です。(1)の $v_B$ と同じ値になります。
$v_E = \sqrt{2gr}$

(1) A点での速さ $v$

ばねを放すと弾性エネルギーが運動エネルギーに変わります。左側は「滑らか」なので損失ゼロです。
1.左は滑らかなので摩擦なし。❹ばねの弾性E $U = \frac{1}{2}ka^2$ がそのまま運動Eに変わります。
2.❸エネルギー保存則より $\frac{1}{2}ka^2 = \frac{1}{2}mv^2$ です。
3.解くと $v^2 = ka^2/m$、よって $v = a\sqrt{k/m}$ です。
$v = a\sqrt{k/m}$

(2) 縮み $a/2$ のときの速さ $u$

ばねがまだ途中まで縮んでいて、エネルギーが全部は変換されていません。「最初のばねE ＝ 残りのばねE ＋ 運動E」です。
1.❸エネルギー保存則で「最初の弾性E ＝ 残りの弾性E ＋ 運動E」を立てます。$\frac{1}{2}ka^2 = \frac{1}{2}k\!\left(\frac{a}{2}\right)^2 + \frac{1}{2}mu^2$
2.左辺 − 右辺第1項 = $\frac{1}{2}k(a^2 - a^2/4) = \frac{3}{8}ka^2$
3.これが $\frac{1}{2}mu^2$ に等しいので $u = a\sqrt{3k/(4m)}$ です。
$u = a\sqrt{3k/(4m)}$

(3) ばねを $a$ 縮める外力の仕事 $W$

はじめも終わりも静止 → 運動Eの変化ゼロ → 仕事がそのままばねのEに。
1.静止→静止で運動Eの変化は0なので、外力の仕事がすべて❹弾性E に蓄えられます。$W = \frac{1}{2}ka^2$ です。
$W = \frac{1}{2}ka^2$

(4) A通過後、B点で停止。距離AB

摩擦区間で運動Eが摩擦熱に変わって止まります。「運動E ＝ 摩擦力 × 距離」の1本です。
1.A点で速さ $v$ → B点で停止。❸エネルギー保存則（摩擦あり）で $\frac{1}{2}mv^2 = \mu mg \cdot \text{AB}$
2.AB について解くと $\text{AB} = v^2/(2\mu g)$ です。
$\text{AB} = v^2/(2\mu g)$

(5) 右が30°斜面（摩擦$\mu$）のとき、最高点Cまでの距離AC

斜面なので「位置Eの増加」と「摩擦熱」の2つに運動Eが分かれます。
1.運動E → 位置Eの増加＋摩擦熱。❸エネルギー保存則（摩擦あり）を立てます。
2.$\frac{1}{2}mv^2 = mg\sin 30° \cdot \text{AC} + \mu mg\cos 30° \cdot \text{AC}$
3.右辺をまとめると $mg(\sin 30° + \mu\cos 30°)\cdot\text{AC}$
4.AC について解くと $\text{AC} = v^2/\{g(1+\sqrt{3}\,\mu)\}$ です。
$\text{AC} = v^2/\{g(1+\sqrt{3}\,\mu)\}$

(1) 衝突直後の速度 $v$（P）, $V$（Q）

未知数が2つなので式を2本用意します。運動量保存で1本、反発係数の定義でもう1本です。
1.未知数は衝突後の $v$（P）と $V$（Q）の2つです。
2.❺運動量保存：$mv_0 = mv + MV$ ……①
3.❻反発係数の定義：$e = (V - v)/(v_0 - 0)$、整理すると $V - v = ev_0$ ……②
4.②より $V = v + ev_0$ ……②' を①に代入します。$mv_0 = mv + M(v + ev_0)$
5.整理すると $v = \frac{(m - eM)v_0}{m + M}$ ……③、②'に戻して $V = \frac{m(1+e)v_0}{m + M}$ です。
$v = (m-eM)v_0/(m+M)$　　$V = m(1+e)v_0/(m+M)$

(2) Pが受けた力積

力積＝運動量の変化。衝突前後のPの運動量はもうわかっているので引き算するだけです。
1.❽力積 $J = mv' - mv$ です。Pの運動量は衝突前 $mv_0$、衝突後 $mv$ なので $J = mv - mv_0$
2.ここに (1) の③を代入して整理すると $J = -\frac{mM(1+e)}{m+M}v_0$（左向き）です。
$J = -mM(1+e)v_0/(m+M)$（左向き）

(3) Pが左へ動く条件

(1) の結果の符号を調べるだけです。
1.(1) の③ $v = (m - eM)v_0/(m+M)$ で、$v < 0$（左向き）になるのは分子 $m - eM < 0$ のときです。
2.$m - eM < 0$ を整理すると $e > m/M$ です。
$e > m/M$

(4) Qが斜面を上りD点で止まり、Bに戻る速さ $V_1$

上りと下りでそれぞれエネルギー保存則を立てます。摩擦は両方向ともエネルギーを奪います。
1.摩擦つき斜面なので❸エネルギー保存則（摩擦あり）を上り・下りで2本立てます。
2.上り（B→D、距離 $l$）：$\frac{1}{2}MV^2 = Mgl\sin\theta + \mu Mg\cos\theta \cdot l$
3.整理すると $l = \frac{V^2}{2g(\sin\theta + \mu\cos\theta)}$ ……①
4.下り（D→B、同じ距離 $l$）：$Mgl\sin\theta = \frac{1}{2}MV_1^2 + \mu Mg\cos\theta \cdot l$
5.整理すると $V_1^2 = 2gl(\sin\theta - \mu\cos\theta)$ ……②
6.②に①を代入して $V_1 = V\sqrt{(\sin\theta - \mu\cos\theta)/(\sin\theta + \mu\cos\theta)}$ です。
$l = V^2/\{2g(\sin\theta+\mu\cos\theta)\}$　　$V_1 = V\sqrt{(\sin\theta-\mu\cos\theta)/(\sin\theta+\mu\cos\theta)}$

衝突前のAの速さ

60°の位置から最下点まで降りるだけ。高さの差からエネルギー保存で求めます。
1.高さの差は $l(1-\cos 60°) = l/2$ です。❸エネルギー保存則より $mg \cdot l/2 = \frac{1}{2}mv_0^2$
2.解くと $v_0 = \sqrt{gl}$ です。
$v_0 = \sqrt{gl}$

(1) 完全弾性衝突（$e=1$）→ Bの速さ

❺運動量保存と❻反発係数($e=1$)の2式を連立します。
1.❺運動量保存：$mv_0 = mv_A' + 2m \cdot v_B$ ……①
2.❻反発係数（$e=1$）：$v_B - v_A' = v_0$ ……②
3.②より $v_A' = v_B - v_0$ を①に代入して整理すると $v_B = \frac{2}{3}v_0 = \frac{2}{3}\sqrt{gl}$ です。
$v_B = \frac{2}{3}\sqrt{gl}$

(2) Aが衝突後静止する場合の反発係数

$v_A' = 0$ がわかっているので未知数が1つ減り、運動量保存ですぐ解けます。
1.❺運動量保存に $v_A' = 0$ を入れます。$mv_0 = 2m \cdot v_B'$ → $v_B' = v_0/2$ です。
2.❻反発係数の定義に代入します。$e = (v_B' - 0) / v_0 = (v_0/2)/v_0$
3.よって $e = 1/2$ です。
$e = 1/2$

(3) (2)のときBの上昇高さ

衝突後のBは速さ $v_0/2$ で動き出して上昇。運動E→位置Eの変換です。
1.❸エネルギー保存則で $\frac{1}{2}(2m)(v_0/2)^2 = (2m)g\Delta h$
2.整理すると $\Delta h = v_0^2/8g = gl/(8g) = l/8$ です。
$\Delta h = l/8$

(4) 弾丸C（質量$M_C$）をBに撃ち込み一体化。$v' = v_C/5$ の条件

「一体になる」＝完全非弾性衝突。運動量保存を1本立てて条件を代入します。
1.❺運動量保存：$M_C v_C = (2m + M_C) \cdot v'$
2.$v' = v_C/5$ を代入します。$M_C v_C = (2m + M_C) \cdot v_C/5$
3.両辺を $v_C$ で割って整理すると $5M_C = 2m + M_C$、$M_C = m/2$ です。
$M_C = m/2$

(5) (4)で失われた力学的エネルギー

「衝突前の運動E − 衝突後の運動E」を計算します。
1.衝突前の運動E：$\frac{1}{2}M_C v_C^2 = \frac{1}{2} \cdot \frac{m}{2} \cdot v_C^2 = \frac{mv_C^2}{4}$
2.衝突後の運動E：$\frac{1}{2}(2m + m/2)(v_C/5)^2 = \frac{1}{2} \cdot \frac{5m}{2} \cdot \frac{v_C^2}{25} = \frac{mv_C^2}{20}$
3.差は $\frac{mv_C^2}{4} - \frac{mv_C^2}{20} = \frac{mv_C^2}{5}$（衝突前の4/5が失われます）。
$\Delta E = mv_C^2/5$

(1) Aの着地時間

Aは真上に投げ上げ。地面に戻る＝高さ0の条件を式にして解きます。
1.❼斜方投射の鉛直の式で $y = vt - \frac{1}{2}gt^2$ です。$y = 0$ を解きます。
2.$y = 0$ とすると $t(v - \frac{1}{2}gt) = 0$ です。$t = 0$ は打ち上げの瞬間です。
3.もう一つの解は $v - \frac{1}{2}gt = 0$ より $t = 2v/g$ です。
$t = 2v/g$

(2) BがAに衝突する条件 → $\sin\alpha$

「衝突する」＝同じ時刻に同じ高さ。$y_A = y_B$ の条件を立てれば $\alpha$ が出ます。
1.A：$y_A = vt - \frac{1}{2}gt^2$、B：$y_B = V\sin\alpha \cdot t - \frac{1}{2}gt^2$
2.$y_A = y_B$ とすると、$-\frac{1}{2}gt^2$ が共通で打ち消し合い、$vt = V\sin\alpha \cdot t$
3.両辺を $t$ で割ると $\sin\alpha = v/V$ です。
$\sin\alpha = v/V$

(3) Aの最高点で衝突 → PQ間距離 $l$

Aの最高点の時刻に、Bが水平方向にどれだけ進んだかが距離 $l$ です。
1.Aが最高点に着く時刻は、❶等加速度 $v_y = v - gt = 0$ より $t^* = v/g$ ……①
2.$\cos\alpha$ を求めます。$\sin\alpha = v/V$ より $\cos\alpha = \sqrt{1 - v^2/V^2} = \sqrt{V^2 - v^2}/V$ ……②
3.PQ間距離 $l =$ Bの水平移動距離 $= V\cos\alpha \cdot t^*$ に①②を代入します。$l = \sqrt{V^2 - v^2} \cdot v/g$ です。
$l = v\sqrt{V^2 - v^2}\,/\,g$

(4) 最高点で合体 → 合体直後の速度

最高点ではA, Bとも鉛直速度が0。水平方向の運動量保存を立てます。
1.最高点ではA, Bとも鉛直速度0です。Aは真上に投げたので水平速度も0。Bの水平速度は $V\cos\alpha$ です。
2.「合体」＝完全非弾性衝突。❺運動量保存（水平）：$M \cdot V\cos\alpha = (m+M) \cdot v'$
3.よって $v' = MV\cos\alpha/(m+M)$（水平のみ。鉛直は0）です。
水平: $MV\cos\alpha/(m+M)$　　鉛直: $0$

(5) 落下点のPからの距離 $x$

合体後は最高点 $v^2/(2g)$ からの水平投射。落下時間と水平距離を順に求めます。
1.最高点の高さ $h_0 = v^2/(2g)$ です。落下時間は❶等加速度 $h_0 = \frac{1}{2}g\tau^2$ より $\tau = v/g$ です。
2.水平移動距離 $= v' \cdot \tau = \frac{MV\cos\alpha}{m+M} \cdot \frac{v}{g}$ に $\cos\alpha$ を代入して整理します。
3.Pからの距離は $x = \frac{Mv\sqrt{V^2-v^2}}{(m+M)g}$ です。
$x = Mv\sqrt{V^2-v^2}\,/\,\{(m+M)g\}$

(1) R放出後、P·Qの速さ

宇宙空間で外力なし。初めに全体が静止しているので、運動量の合計はずっと0です。相対速度の条件も合わせて2式連立します。
1.❺運動量保存（合計0）：$m \cdot v_R + 3m \cdot v_{PQ} = 0$ ……①
2.「P·Qから見て速さ $u$」→ 相対速度の条件：$v_{PQ} - v_R = u$ ……②
3.①より $v_R = -3v_{PQ}$ ……①' を②に代入します。$v_{PQ} - (-3v_{PQ}) = u$ → $4v_{PQ} = u$
4.よって $v_{PQ} = u/4$（右向き）です。
$v_{PQ} = u/4$（右向き）

(2) R放出に要したエネルギー

最初は全体静止で運動E＝0。放出後にR, P·Qが動いているので、増えた運動Eの合計がそのまま使ったエネルギーです。
1.(1)の①'より $v_R = -3 \cdot u/4 = -3u/4$（左向き）です。
2.Rの運動E：$\frac{1}{2}m(3u/4)^2 = \frac{9mu^2}{32}$、P·Qの運動E：$\frac{1}{2}(3m)(u/4)^2 = \frac{3mu^2}{32}$
3.合計は $\frac{9mu^2}{32} + \frac{3mu^2}{32} = \frac{12mu^2}{32} = \frac{3mu^2}{8}$ です。
$E = 3mu^2/8$

(3) Q放出後のPの速さ

(1)と同じ考え方を2段目に使います。今度の系はP·Q（質量 $3m$、速度 $u/4$）です。
1.分離前の運動量が保存されるので、❺運動量保存：$m \cdot v_Q + 2m \cdot v_P = 3m \cdot u/4$ ……①
2.「Pから見て速さ $u$」→ 相対速度：$v_P - v_Q = u$ ……②
3.②より $v_Q = v_P - u$ ……②' を①に代入します。$m(v_P - u) + 2mv_P = 3mu/4$
4.整理すると $3mv_P = 3mu/4 + mu = 7mu/4$、$v_P = 7u/12$（右向き）です。
$v_P = 7u/12$（右向き）

(1) 台固定。B→Cで停止（距離$l$）。動摩擦$\mu$は？

高さ $h$ から降りて摩擦で停止。「位置E ＝ 摩擦熱」の1本で $\mu$ が出ます。
1.❸エネルギー保存則（摩擦あり）：$mgh = \mu mg \cdot l$
2.両辺を $mg$ で割ると $h = \mu l$、よって $\mu = h/l$ です。
$\mu = h/l$

(2-ア) 台自由。$v$, $V$ の関係式

台が動けるので、Pが滑ると台は反対に動きます。運動量保存とエネルギー保存の2本が関係式です。
1.水平方向に外力がないので、❺運動量保存：$mv + MV = 0$ ……①
2.曲面に摩擦なしなので、❸エネルギー保存則：$mgh = \frac{1}{2}mv^2 + \frac{1}{2}MV^2$ ……②
3.この①②の2本が求める関係式です。
① $mv + MV = 0$　　② $mgh = \frac{1}{2}mv^2 + \frac{1}{2}MV^2$

(2-イ) $v$ と $V$ を求める

①から $V$ を $v$ で表して②に代入すれば、$v$ だけの式になります。
1.①より $V = -mv/M$ ……①' です。
2.①'を②に代入します。$mgh = \frac{1}{2}mv^2 + \frac{1}{2}M \cdot \frac{m^2 v^2}{M^2} = \frac{1}{2}mv^2\!\left(1 + \frac{m}{M}\right)$
3.整理すると $v^2 = \frac{2Mgh}{M+m}$、$v = \sqrt{\frac{2Mgh}{M+m}}$ です。①'に戻して $V$ も出ます。
$v = \sqrt{2Mgh/(M+m)}$　　$V = -(m/M)\sqrt{2Mgh/(M+m)}$

(2-ウ) Pが台に対して止まったとき、台はどうなるか

Pと台が同じ速度 $v_{\text{共}}$ で動いている状態。運動量保存に代入すればわかります。
1.①はいつでも成り立ちます。Pと台が同じ速度 $v_{\text{共}}$ → $(m + M)v_{\text{共}} = 0$
2.$m + M \neq 0$ なので $v_{\text{共}} = 0$ です。Pも台も停止します。
Pが台に対して停止すると、台も停止します

① $h = 4.9$ m, $v_0 = 5.0$ m/s

水平投射では水平方向は等速、鉛直方向は自由落下です。落下時間を求めてから水平距離を計算します。
1.水平投射では、水平方向は速さ $v_0$ の等速直線運動、鉛直方向は初速0の自由落下です。
2.鉛直方向で落下時間を求めます。$h = \frac{1}{2}gt^2$ より $4.9 = \frac{1}{2} \times 9.8 \times t^2$
3.整理すると $t^2 = 1.0$、$t = 1.0$ s です。
4.水平方向の変位は $x = v_0 t = 5.0 \times 1.0 = 5.0$ m です。
$x = 5.0$ m

② $h = 44.1$ m, $v_0 = 8.0$ m/s

①と同じ手順です。落下時間→水平距離。
1.$h = \frac{1}{2}gt^2$ に代入します。$44.1 = \frac{1}{2} \times 9.8 \times t^2$
2.整理すると $t^2 = 9.0$、$t = 3.0$ s です。
3.$x = v_0 t = 8.0 \times 3.0 = 24$ m です。
$x = 24$ m

① $v_0 = 19.6$ m/s, $\theta = 30°$

斜方投射では速度を水平・鉛直に分解します。地面に戻る時刻（滞空時間）を求めてから水平距離を計算します。
1.速度を分解します。水平 $v_x = v_0\cos 30° = 19.6 \times \frac{\sqrt{3}}{2} = 9.8\sqrt{3}$ m/s、鉛直 $v_y = v_0\sin 30° = 9.8$ m/s
2.地面に戻る時刻は $t = \frac{2v_y}{g} = \frac{2 \times 9.8}{9.8} = 2.0$ s です。
3.水平距離は $x = v_x t = 9.8\sqrt{3} \times 2.0 = 19.6\sqrt{3} \approx 34$ m です。
$x = 19.6\sqrt{3} \approx 34$ m

② $v_0 = 4.9\sqrt{2}$ m/s, $\theta = 45°$

①と同じ手順です。
1.水平 $v_x = 4.9\sqrt{2} \times \cos 45° = 4.9\sqrt{2} \times \frac{\sqrt{2}}{2} = 4.9$ m/s、鉛直 $v_y = 4.9$ m/s
2.$t = \frac{2 \times 4.9}{9.8} = 1.0$ s です。
3.$x = 4.9 \times 1.0 = 4.9$ m です。
$x = 4.9$ m

③ $v_0 = 9.8\sqrt{3}$ m/s, $\theta = 60°$

①と同じ手順です。
1.水平 $v_x = 9.8\sqrt{3} \times \cos 60° = 4.9\sqrt{3}$ m/s、鉛直 $v_y = 9.8\sqrt{3} \times \sin 60° = 14.7$ m/s
2.$t = \frac{2 \times 14.7}{9.8} = 3.0$ s です。
3.$x = 4.9\sqrt{3} \times 3.0 = 14.7\sqrt{3} \approx 25$ m です。
$x = 14.7\sqrt{3} \approx 25$ m

(1) $m = 1.0$ kg, $v = 3.0$ m/s（右）, $F = 15$ N（左から）, $\Delta t = 0.10$ s

力積＝運動量の変化です。右向きを正として、力積を求めてから速度を出します。
1.右向きを正とします。力は左から（右向き）なので、力積は $J = F\Delta t = 15 \times 0.10 = 1.5$ N·s（右向き）です。
2.❽力積＝運動量の変化より $mv' = mv + J = 1.0 \times 3.0 + 1.5 = 4.5$ kg·m/s
3.$v' = 4.5 / 1.0 = 4.5$ m/s です。
$v' = 4.5$ m/s

(2) $m = 3.0$ kg, $v = 2.0$ m/s（右）, $F = 30$ N（左から）, $\Delta t = 0.20$ s

(1)と同じ手順です。
1.力積は $J = 30 \times 0.20 = 6.0$ N·s（右向き）です。
2.$mv' = 3.0 \times 2.0 + 6.0 = 12.0$ kg·m/s
3.$v' = 12.0 / 3.0 = 4.0$ m/s です。
$v' = 4.0$ m/s

(1) $m = 2.0$ kg, $v = 4.0$ → $v' = 5.0$ m/s, $\Delta t = 0.10$ s

力積＝運動量の変化から力 $F$ を逆算します。
1.右向きを正とします。運動量の変化は $\Delta p = mv' - mv = 2.0 \times 5.0 - 2.0 \times 4.0 = 2.0$ kg·m/s です。
2.$F\Delta t = \Delta p$ より $F \times 0.10 = 2.0$
3.$F = 2.0 / 0.10 = 20$ N です。
$F = 20$ N

(2) $m = 3.0$ kg, $v = 4.0$ → $v' = 6.0$ m/s, $\Delta t = 0.10$ s

(1)と同じ手順です。
1.$\Delta p = 3.0 \times 6.0 - 3.0 \times 4.0 = 6.0$ kg·m/s です。
2.$F \times 0.10 = 6.0$
3.$F = 60$ N です。
$F = 60$ N

(1) A(3.0 kg, 3.0 m/s) → B(1.0 kg, 2.0 m/s) に衝突、衝突後 A は 2.5 m/s

衝突の前後で運動量の合計は変わりません。❺運動量保存則を立てて $v'$ を求めます。
1.右向きを正として、❺運動量保存則を立てます。
2.衝突前の運動量の合計：$3.0 \times 3.0 + 1.0 \times 2.0 = 11.0$ kg·m/s
3.衝突後の運動量の合計：$3.0 \times 2.5 + 1.0 \times v' = 7.5 + v'$
4.保存則より $11.0 = 7.5 + v'$、よって $v' = 3.5$ m/s です。
$v' = 3.5$ m/s
